Reclusive Raven

personal tools · Oshan Mudannayake

Reclusive Raven is the name I file my own tools under: small programs I write to run errands for myself and, now and then, my family. They run on my computer, and nobody else can sign up for them.

Flux

Flux keeps track of job alerts. Once the owner of a Gmail account connects it, Flux reads the job-alert emails that arrive there, pulls out the listings, and checks them against the filters that person has saved. The results go into a database on my computer.

Access to a Google account

Connecting an account brings up Google's consent screen, which asks for Gmail access. That lets Flux read and label job alerts, and send the digests and job applications the owner sets up. The privacy policy explains what happens to that data.
